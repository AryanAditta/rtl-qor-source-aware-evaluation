# Public release status

This repository is the curated manuscript-stage release, not the complete project archive.

## Included now

- R4.1 final freeze/decision records and claim boundaries
- frozen M12–M14 preregistered protocol
- M12 manuscript-facing peer-comparable metrics, External83 regime table and metric policy
- M13 development-only ablation metrics, paired deltas, seed-noise record and interpretation
- M14 gate, coverage, audit and diagnostic summaries, with the explicit no-accuracy-comparison decision
- all 83 original External83 Area/Timing frozen prediction-label pairs
- all 39 Reserve50 prospective Area paired cases
- all 39 Source50 prospective TimingV2 paired cases
- all 39 Source50 secondary Area paired cases
- cohort applicability/support counts
- a small script for recomputing the released primary/secondary metrics and saved-style fresh bootstrap intervals
- reproducibility and third-party redistribution documentation

## Deliberately not included

- the complete Google Drive directory
- the ~298 MB historical source-artifact index
- the ~276 MB M14 diagnostic result bundle
- 100+ superseded/intermediate notebooks
- redundant checkpoints and debugging files
- private/supervisor documents
- unrelated project files
- third-party RTL/dependencies without confirmed redistribution permission

## Not claimed by this release

This repository does not claim full clean-room regeneration of every physical label or every historical fitted model. The strongest supported public use is manuscript claim checking from frozen predictions/results, together with inspection of the final evidence protocol and applicability boundaries.

A versioned archival release/DOI and final license should be added after author/supervisor approval of the submission package.
